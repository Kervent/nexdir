# Getting help

- **How do I…? / Something seems off** — first look at *Help & Support* in Nexdir (offline help
  and common problems). Then ask in the Nexdir Discord **#support** forum, one post per question,
  once its invite link is published in the README. Until then, open a GitHub issue. Include your
  Nexdir version and Windows version.
- **Bug** — in Nexdir choose *Help → Report a Bug*: you fill in a short form, review exactly what
  will be shared (paths, user names and e-mail addresses are removed), and Nexdir opens the
  prefilled GitHub form in your browser. Or open a [bug report](../../issues/new/choose) on
  GitHub directly. Say whether any data was lost or changed.
- **Idea** — *Help → Request a Feature* in Nexdir, or open a feature request on GitHub after
  checking the [roadmap](docs/ROADMAP.md).
- **Security vulnerability** — report it privately, see [SECURITY.md](SECURITY.md).

Please never share personal files, passwords or screenshots with private information.

Nexdir is a volunteer project without paid support. Answers usually come within a few days.
