**How to get help**

1. Search existing posts first — your question may already be answered.
2. Create **one post per problem** with a short, specific title.
3. Include:
   • Nexdir version (Help → About or the installer name)
   • Windows version (e.g. Windows 11 24H2)
   • What you tried and what happened
4. Use the tags: **Open** while waiting, **Needs Info** if the team asked a question, **Solved** when it works.

⚠️ **Privacy:** never post passwords, tokens or personal data. Blur private file names and paths in screenshots. Do not upload private files.

🐞 Found a bug? Use #bug-reports. 🔒 Security problem? Report it privately: {links.security}
