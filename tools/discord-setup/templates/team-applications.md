# Team applications — internal process

Open positions: **Moderator**, **Support Team**, **Developer**, **Core Developer**.

**How applicants apply**
Applicants send a DM to a moderator or administrator with:
```
Position:
Discord name:
GitHub profile (for development roles):
Time per week:
Relevant experience:
Why do you want to help?
Languages spoken:
```

**Review process**
1. Post the application here as a thread (one per applicant). Do not copy private data beyond what is needed.
2. Review by: Founder/Administrator for all positions, Core Developers for development roles, Moderators for moderation/support roles.
3. Development roles: at least one merged pull request or substantial review work first.
4. Decision within 14 days; applicants get a friendly answer either way.

**Rules**
- Applications are **never accepted automatically**. Roles are assigned manually after a decision.
- Project roles (e.g. Developer) and server permissions are separate. Nobody receives Administrator through this process.
- Remove inactive team roles after 90 days of inactivity, after a friendly check-in.
