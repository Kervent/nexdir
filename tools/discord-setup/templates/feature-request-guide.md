**How to suggest a feature**

1. Search first and react with 👍 to existing ideas instead of posting duplicates.
2. One idea per post, with a clear title.
3. Describe:
   • **The problem** — what is hard or impossible today?
   • **Your idea** — how should Nexdir help?
   • **Alternatives** you considered (optional)

Tags show the status: Suggestion → Under Review → Planned → In Progress → Implemented, or Declined (with a reason).

Nexdir's priorities are data safety, correctness and privacy — ideas that need telemetry, ads or a cloud account will be declined.
