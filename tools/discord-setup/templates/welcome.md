# Welcome to the Nexdir Community 👋

**Nexdir** is a modern, open-source file manager for Windows — *a smarter way to manage your files.* It is free, has no ads, no tracking and no account requirement.

This server is the official place for:
- **Help** with Nexdir → #support
- **Bug reports** → #bug-reports
- **Ideas and feature requests** → #feature-requests
- **Development** and contributions → #development-chat and #contribution-help
- **News and releases** → #announcements and #releases

**Getting started**
1. Read the #rules.
2. Pick the topics and notifications you care about in *Channels & Roles*.
3. Say hello in #general!

Downloads, documentation and the source code are linked in #resources.

Want to help? Developers, testers, translators, writers and helpers are all welcome. See #contribution-help or the contribution guide: {links.contributing}
