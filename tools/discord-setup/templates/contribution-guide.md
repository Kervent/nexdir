# Contributing to Nexdir

Everyone can help — code, testing, documentation, translation and support all count.

**Developers**
1. Read the contribution guide: {links.contributing}
2. Set up the project (Node.js, Rust, VS Build Tools) — instructions are in the docs: {links.docs}
3. Pick an issue, comment that you are working on it, fork the repository and open a pull request.
4. Run the tests before submitting. Changes to file operations need tests in temporary folders.

**Testers** — try pre-releases and report bugs in #bug-reports. Ask for the *Beta Tester* role.
**Writers & translators** — documentation improvements are welcome as pull requests.
**Helpers** — answering questions in #support is a great way to contribute.

Ask questions about builds, code or pull requests here in #contribution-help. Technical decisions are documented on GitHub so everyone can follow them.

Interested in joining the team? See the application process (ask a moderator).
