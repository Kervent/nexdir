**How to report a bug**

Please create one post per bug and copy this template:

```
Nexdir version:
Windows version:
What happened:
Steps to reproduce:
1.
2.
3.
Expected behaviour:
Actual behaviour:
Did any file get lost or changed? (yes / no / not sure)
```

Optional: screenshots or logs — **remove personal data first** (names, paths, file contents). Never upload private files.

Tags are managed by the team: Open → Investigating → Confirmed → Fixed → Closed. "Needs Info" means we need your answer.

🔒 **Security vulnerabilities must not be posted here.** Report them privately: {links.security}
Also on GitHub: {links.github}/issues
