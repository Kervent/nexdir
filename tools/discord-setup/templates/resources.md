**Download safely**
- Only download Nexdir from the official GitHub releases page above.
- Each release lists SHA-256 checksums (`SHA256SUMS.txt`). Compare them before installing.
- Early releases are not code-signed yet, so Windows SmartScreen may show a warning. Never run copies from other sources.
